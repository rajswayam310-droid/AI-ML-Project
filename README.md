📌 ABOUT THE PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
We analyzed 3 Million+ grocery sales transactions from the 
Corporacion Favorita dataset (Kaggle) to predict demand, 
detect stockout risks, and generate automated replenishment 
recommendations for dark store inventory management.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🤖 MODELS BUILT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ H2O Gradient Boosting — R² = 0.721 | RMSE = 654
✅ Linear Regression — R² = 0.53 (Baseline)
✅ Decision Tree Classifier — 99.99% Accuracy
✅ Logistic Regression — 94.3% Overall Accuracy
✅ K-Means Clustering — 5 Store Segments
